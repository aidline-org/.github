**Aidline helps diaspora communities fund disaster relief and climate work back home, with proof it landed.**

Donations wait in a Soroban smart contract on Stellar and are released one milestone at a time, only after an independent verifier publishes evidence of the work. If a campaign stalls, donors reclaim what was never spent.

| Repository | What it does |
| --- | --- |
| [aidline-contracts](https://github.com/aidline-org/aidline-contracts) | Rust / Soroban escrow: campaigns, milestones, verifiers, refunds |
| [aidline-backend](https://github.com/aidline-org/aidline-backend) | TypeScript indexer and API: campaigns, proofs, donors, stats |
| [aidline-frontend](https://github.com/aidline-org/aidline-frontend) | Next.js app: connect any Stellar wallet, donate, verify, follow every payout |

### Contributing

We welcome contributors of every level. Each repository has issues labelled by complexity and `good first issue`, with clear acceptance criteria. Start with the CONTRIBUTING guide in the repo you want to work on.

Aidline runs on Stellar testnet and has not been audited. Please do not send real funds.
